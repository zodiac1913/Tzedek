# Tzedek Security Profile

Tzedek is a browser-run accessibility review tool. It scans the active page DOM, reports accessibility findings locally in the browser, and provides links or snippets that help reviewers inspect and fix issues.

## Execution Model

- Tzedek runs only when the reviewer explicitly launches it through the extension action or bookmarklet.
- The extension uses Manifest V3.
- The extension injects packaged Tzedek runtime files into the active HTTP or HTTPS tab.
- The extension does not run on browser-internal pages, local extension pages, or non-HTTP(S) URLs.
- The runtime marks its own injected DOM with `data-smlc="1"` and Tzedek-owned classes so later scans can exclude Tzedek UI from page findings.

## Browser Extension Permissions

Current extension permissions are intentionally narrow:

- `activeTab`: grants temporary access only to the active tab after a user click.
- `scripting`: injects the packaged Tzedek runner into the clicked tab.

Tzedek does not request these higher-risk permissions:

- no `debugger`
- no persistent host permissions
- no `tabs`
- no `storage`
- no cookies or web request permissions
- no native messaging

## Data Handling

- Tzedek performs analysis in the user's browser.
- Tzedek does not transmit audit results to a server.
- Tzedek does not collect telemetry.
- Tzedek does not store page content or findings in extension storage.
- Tzedek keeps the latest report in page memory as `window.__smlComplianceLastReport` for same-session reviewer access.
- Export actions create local JSON or CSV files through browser download APIs.
- Clipboard actions are initiated by the user and copy only the selected fix text or color value.

## Network Behavior

Extension mode:

- Loads Tzedek runtime, CSS, issue guide, and image assets from packaged extension files.
- Does not load Bootstrap Icons, fonts, scripts, or other assets from a CDN by default.
- Same-origin broken-link checks may issue `HEAD` or `GET` requests to URLs already present on the audited page, using `credentials: "same-origin"` and `redirect: "manual"`.
- Cross-origin links are not fetched by the broken-link checker.

Bookmarklet mode:

- Loads Tzedek files from the configured bookmarklet asset host.
- The configured host should be approved before production use.
- Public bookmarklet distribution should use HTTPS and immutable versioned asset URLs.

## DOM Injection And Rendering

- The extension service worker injects only packaged extension URLs into the active tab.
- The runner uses DOM APIs to build the report panel.
- Runtime finding messages may contain Tzedek-generated HTML for code samples, links, swatches, and action buttons.
- External page content included in finding messages is escaped before rendering unless explicitly generated by Tzedek helpers.
- Tzedek UI controls are made untabbable by default to avoid disrupting the audited page's keyboard flow.

## Remote References

Tzedek may render normal links to external documentation, such as MDN, W3C WCAG understanding pages, and the Tzedek GitHub repository. These links open only when the reviewer activates them.

## Known Review Considerations

- The broken-link checker intentionally touches same-origin application URLs found on the reviewed page. Disable `checkBrokenLinks` if a test environment should avoid same-origin link probes.
- The bookmarklet delivery model depends on a trusted asset host. For Medicare use, prefer the packaged extension or an approved internal HTTPS asset host.
- Tzedek is a review assistant, not an enforcement gateway. Findings should be confirmed by accessibility reviewers before release decisions.

## Recommended Security Review Checks

- Confirm extension permissions remain limited to `activeTab` and `scripting`.
- Confirm no `debugger`, persistent host permissions, telemetry endpoint, or extension storage use is introduced.
- Confirm packaged extension assets are used instead of remote script/style CDNs.
- Confirm exported reports are local files and are not uploaded.
- Confirm bookmarklet production hosting uses HTTPS and approved internal or public release infrastructure.
